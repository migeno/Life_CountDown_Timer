# Life Countdown Timer — のこり時間

日本人の公的統計（生命表）にもとづいて、**平均余命**と**健康寿命**までの残り時間をカウントダウンするシンプルなWebアプリです。

`index.html` 1ファイルで完結し、ビルド不要・オフラインで動作します。

## 使い方

`index.html` をブラウザで開き、生年月日・誕生時刻・性別を選ぶだけです。誕生時刻がわからない場合は、初期値の 12:00 のままで構いません。

```bash
open index.html
```

生年月日・性別はブラウザの localStorage にのみ保存され、外部には一切送信されません。

## 表示内容

- 平均余命 / 健康寿命までの残り日数と 時:分:秒 のライブカウントダウン
- 推定到達年齢と、その年月日
- 人生の進捗バー、いまの年齢、生きてきた日数、残り週数・月数
- 現在の年齢を起点にした「その年齢まで生きる確率」
- 推定を超えている場合は、超えてからの経過日数に表示が切り替わります

## データ出典

| 項目 | 出典 | 値 |
|---|---|---|
| 年齢別平均余命 `ex`・生存数 `lx`（0〜105歳） | 厚生労働省「[令和6(2024)年簡易生命表](https://www.mhlw.go.jp/toukei/saikin/hw/life/life24/index.html)」 | 平均寿命 男 81.09年 / 女 87.13年 |
| 健康寿命 | 厚生労働省 令和4(2022)年値 | 男 72.57年 / 女 75.45年 |

公式のExcel（`life24-12.xlsx`）から男女それぞれ0〜105歳の値をすべて抽出し、`index.html` 内に埋め込んでいます。

## 計算方法

1. 誕生日から小数点付きの現在年齢を求め、生命表を線形補間して**その年齢での平均余命**を算出する
2. `推定寿命 = 現在年齢 + 平均余命`
3. `健康寿命の目安 = 推定寿命 −（平均寿命 − 健康寿命）`
   - 差は男 8.48年 / 女 11.64年。0歳に適用すると男 72.60年となり公式値 72.57年とほぼ一致します
   - 単純な「健康寿命 − 現在年齢」だと高齢の場合に負の値になるため、この方式を採用しています
4. `その年齢まで生きる確率 = lx(目標年齢) ÷ lx(現在年齢)`

## 注意

これは日本人全体の統計にもとづく平均像であり、個人の余命を予測するものではありません。
