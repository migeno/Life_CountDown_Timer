# Life Countdown Timer — のこり時間

日本人の公的統計（生命表）にもとづいて、**平均余命**と**健康寿命**までの残り時間をカウントダウンするシンプルなWebアプリです。

`index.html` 1ファイルで完結し、ビルド不要・オフラインで動作します。

## 使い方

`index.html` をブラウザで開き、生年月日・誕生時刻・性別を選ぶだけです。誕生時刻がわからない場合は、初期値の 12:00 のままで構いません。

```bash
open index.html
```

生年月日・性別はブラウザの localStorage にのみ保存され、外部には一切送信されません。

外観は設定画面で「システム / ライト / ダーク」から選べます。システムを選ぶとOSの設定に追従し、使用中にOS側が切り替わってもその場で反映されます。

「人生カレンダー」「これからの節目」「あなたの年齢での統計」「その年齢まで生きる確率」は、設定画面のチェックボックスで表示・非表示を切り替えられます。**初期はすべてオフ**なので、必要なものだけチェックしてください。

生活習慣（喫煙・身長体重・運動習慣・飲酒）は任意入力です。未選択の項目は「日本人の平均」として扱われ、すべて未選択なら簡易生命表そのままの値が出ます。

## 表示内容

- 平均余命 / 健康寿命までの残り時間の 時:分:秒 ライブカウントダウン
- 数字の横の「›」で、残りの表示を **日数 ⇄ 年月日** に切り替え（選んだ表示は次回も保持されます）
- カウントダウンの下を流れる一言（古典の言葉と、表示中の値に連動するもの12種をランダムに）
- 推定到達年齢と、その年月日
- 人生の進捗バー、いまの年齢、生きてきた日数、残り週数・月数
- **人生カレンダー** — 1マス＝1週間で人生を描き、過ぎた週・元気に動けそうな週・その後を塗り分け。今週のマスは点滅し、「誕生」と登録したイベント（6件まで）に印と名前が付きます。一覧は開閉式で、経過／残りを「◯年◯か月◯日」と日数の両方で表示します
- **これからの節目** — 次の誕生日、10歳の区切り、生きて◯万日までの残り日数
- **生まれた年との比較** — 生まれた年の平均寿命と現在との差
- 現在の年齢を起点にした「その年齢まで生きる確率」と、その生存曲線のグラフ（半数が亡くなる年齢の目印つき。生活習慣を入れた場合は補正なしの曲線も点線で重ねます）
- 生活習慣による補正の内訳（項目ごとに ±何日。リストとウォーターフォールチャートを切り替え可能）と、「いま禁煙したら +N日」などの試算
- 推定を超えている場合は、超えてからの経過日数に表示が切り替わります

iPhone は Safari で開いて共有ボタン →「ホーム画面に追加」で、アイコン付きのアプリとして起動できます。

## アイコン

`icons/` に各サイズを、ルートに `favicon.ico` と `manifest.json` を置いています。元画像から作り直す場合は次のコマンドです（要 Pillow）。

```bash
python3 tools/make-icons.py path/to/source.png
```

元画像は「白い余白の中に角丸の正方形が置かれた」形を想定しています。白フチを取り除き、角丸の外に残る白を背景のグラデーションで埋めて全面正方形にします。iOS・Android は独自の形にマスクするため、アイコン側では角を丸めません。

## データ出典

| 項目 | 出典 | 値 |
|---|---|---|
| 年齢別平均余命 `ex`・生存数 `lx`（0〜105歳） | 厚生労働省「[令和6(2024)年簡易生命表](https://www.mhlw.go.jp/toukei/saikin/hw/life/life24/index.html)」 | 平均寿命 男 81.09年 / 女 87.13年 |
| 健康寿命 | 厚生労働省 令和4(2022)年値 | 男 72.57年 / 女 75.45年 |
| 喫煙・運動習慣・飲酒のハザード比 | 国立がん研究センター [多目的コホート研究（JPHC）](https://epi.ncc.go.jp/jphc/) | 喫煙 男1.6 / 女1.9 ほか |
| BMIのハザード比 | 日本人7コホート統合解析（Sasazuki et al., [J Epidemiol 2011](https://www.jstage.jst.go.jp/article/jea/21/6/21_JE20100180/_article)） | BMI 23–25 を基準 |
| 各項目の該当割合 | 厚生労働省 国民健康・栄養調査 ほか（一部は推定値） | 基準合わせに使用 |
| 平均寿命の年次推移（1947〜2024） | 令和6年簡易生命表 参考資料２ | 生まれた年との比較に使用 |

公式のExcel（`life24-12.xlsx`）から男女それぞれ0〜105歳の値をすべて抽出し、`index.html` 内に埋め込んでいます。

## 計算方法

1. 誕生日から小数点付きの現在年齢を求め、生命表を線形補間して**その年齢での平均余命**を算出する
2. `推定寿命 = 現在年齢 + 平均余命`
3. `健康寿命の目安 = 推定寿命 −（平均寿命 − 健康寿命）`
   - 差は男 8.48年 / 女 11.64年。0歳に適用すると男 72.60年となり公式値 72.57年とほぼ一致します
   - 単純な「健康寿命 − 現在年齢」だと高齢の場合に負の値になるため、この方式を採用しています
4. `その年齢まで生きる確率 = Π(1 − 補正後の死亡率)`

### 生活習慣の補正

生存数 `lx` から年齢別死亡率 `qx` を復元し、`qx × ハザード比` で生命表を組み直して平均余命を再計算しています。近似誤差を持ち込まないよう、ハザード比1の場合との差分だけを公式の平均余命に加算しています（実測でモデルの再現誤差は 0.005年以内）。

項目ごとの寄与は、ハザード比を1つずつ順に掛けていったときの差として求めています。生命表は掛け算に対して線形ではないため、単純に「その項目を除いたときとの差」を並べると合計が総差と一致しません。この方式なら必ず一致しますが、そのぶん各項目に配分される値は掛ける順番に依存します。

ハザード比は、各項目の日本人での該当割合で重みづけした平均が1になるよう基準を合わせています。生命表そのものが「平均的な日本人」を表しているため、この基準合わせをしないと平均的な回答をした人の値が公式値からずれてしまうためです。

## 注意

- これは日本人全体の統計にもとづく平均像であり、個人の余命を予測するものではありません。医学的な判断には使えません
- 複数の項目は掛け合わせて計算しているため、当てはまる項目が多い人ほど差が大きく出やすくなります
- 飲酒の「飲まない」が基準として不利に出るのは、体調を崩して飲酒をやめた人が含まれるためとされ、飲酒を勧める根拠にはなりません
- 日本人ではやせ側の死亡リスクが高いため、やや太めでもプラス側に出ることがあります。肥満の健康リスクを否定するものではありません
- BMIの「適正体重に近づけたら」は、体重を変えた効果ではなく別々の集団どうしの比較です。すでに適正の範囲（男性 BMI 21〜27／女性 21〜25）に入っている場合は、減量・増量を促す根拠がないため試算を表示しません
- 遺伝的要素と詳細な既往歴は、個人予測に足る精度がないため意図的に採用していません
